# Getting help

- **Using or running Liz**: start with the [README](README.md) and the guides
  in [docs/](docs/). [docs/OPERATIONS.md](docs/OPERATIONS.md) covers deploys,
  scheduled jobs, backups and every secret.
- **Found a bug**: open an issue with the bug report template.
- **Have an idea**: open an issue with the feature request template.
- **Found a security problem**: do not open an issue. Follow
  [SECURITY.md](SECURITY.md).

Liz is maintained by one person, so there is no guaranteed response time and
no support for private deployments beyond the documentation.

## Contacting the maintainer

For anything that should not be public, including Code of Conduct reports,
use GitHub's private reporting
(<https://github.com/jeswinbenedict/LIZ/security/advisories/new>) and say
that the report is not a vulnerability.
